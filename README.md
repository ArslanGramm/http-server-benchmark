# HTTP Server Benchmark

Консольная программа на Python для проверки доступности HTTP-серверов и измерения времени ответа.

## Возможности

- Проверка одного или нескольких HTTP-хостов.
- Настройка количества запросов.
- Подсчёт успешных запросов.
- Подсчёт HTTP-ошибок.
- Подсчёт ошибок соединения.
- Расчёт минимального, максимального и среднего времени ответа.
- Проверка формата URL.
- Чтение списка хостов из файла.
- Сохранение результата в файл.

## Требования

- Python 3.10+
- requests

## Установка

python -m pip install -r requirements.txt

## Запуск

Проверка одного хоста:

python bench.py -H https://ya.ru

Проверка нескольких хостов:

python bench.py -H https://ya.ru,https://google.com -C 5

Чтение хостов из файла:

python bench.py -F hosts.txt -C 5

Сохранение результата:

python bench.py -H https://ya.ru -C 5 -O result.txt

## Аргументы

### -H / --hosts

Список адресов через запятую без пробелов.

### -F / --file

Путь к файлу со списком адресов. Каждый адрес находится на отдельной строке.

### -C / --count

Количество запросов к каждому хосту.

По умолчанию: 1.

### -O / --output

Путь к файлу для сохранения результата.
